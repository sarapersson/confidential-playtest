# Confidential Playtest

A closed feedback community for confidential playtests.

Final project for part 3 of the DevSecOps with Security Specialization course (Swedish higher vocational
education, YH) at NBI/Handelsakademin.

The assignment, *DevSecOps and Virtualized Infrastructure*, asks for a social application, or one with
comparable challenges in protecting user content and personal data, that is deployed, verified and
prepared for secure operation. It covers seven areas: threat modeling, security controls, containers,
CI/CD with security gates, cloud deployment, logging and monitoring, and incident handling.

## Status

Under construction. The repository is built step by step, and this README grows with it.

## Use of AI

I use AI agents for research, comparing alternatives, drafting plans, documentation and code, and
reviewing changes. I treat their output as proposals that I verify through review and tests: claims are
checked against primary sources such as official documentation, and changes are reviewed by a separate
AI agent and tested before I use them. The trade-offs, decisions and commits are my own.
